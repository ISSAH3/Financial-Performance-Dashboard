# DAX Measures Documentation

# Executive Financial Analytics Dashboard

## Project Overview

This document contains the DAX measures developed for the Executive Financial Analytics Dashboard built in Microsoft Power BI using the Microsoft Financial Sample dataset.

The measures support KPI calculations, financial analysis, product performance, regional analysis, dynamic reporting, and executive decision-making.

---

# Financial Measures

## Total Sales

### Purpose
Calculates the total revenue generated.

```DAX
Total Sales =
SUM(FactFinancials[Sales])
```

Used In

- KPI Cards
- Revenue Trend
- Regional Dashboard
- Product Dashboard

# Product Analytics Measures

## Total Products

### Purpose

Counts all unique products.

```DAX
Total Products =
DISTINCTCOUNT(FactFinancials[Product])
```

---

## Average Sales per Product

### Purpose

Calculates average revenue generated by each product.

```DAX
Average Sales per Product =
DIVIDE([Total Sales],[Total Products])
```

---

## Average Profit per Product

### Purpose

Calculates average profit generated by each product.

```DAX
Average Profit per Product =
DIVIDE([Total Profit],[Total Products])
```

---

## Average Units per Product

### Purpose

Calculates the average units sold per product.

```DAX
Average Units per Product =
DIVIDE([Total Units Sold],[Total Products])
```

---

## Top Product

### Purpose

Used In
